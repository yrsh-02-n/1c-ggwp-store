# 1c-ggwp-store

Конфигурация **1С:Предприятие 8.3** для автоматизации закупки, продажи и складского учёта компьютерных комплектующих.

Проект начат во время прохождения профессиональной переподготовки по специальности «1С-программист» и продолжает развиваться. На данный момент добавлены расчёт НДС (сверху), логика перемещения товаров между складами и печатные формы. Следующий шаг — настройка ролей и прав доступа.

---

## 📦 Состав конфигурации

### 🗂 НСИ (нормативно-справочная информация)
- **Справочники:** Номенклатура, Контрагенты, Склады, Организации, Сотрудники, Договоры, Валюты, Единицы измерения, Должности, Банки, Расчётные счета, Ставки НДС.
- **Иерархия номенклатуры:** комплектующие, периферия и т.д.

### 📄 Документы
- **Закупка:** Поступление товаров, Заказ товаров.
- **Продажа:** Реализация товаров, Счёт на оплату, Оказание услуг.
- **Склад:** Перемещение товаров.
- **Финансы:** Выписка банка.
- **Цены:** Регистрация цен.

### 🔄 Движения и регистры
- **Регистры накопления:** Остатки номенклатуры, Продажи, Взаиморасчёты.
- **Регистры сведений:** Цены номенклатуры, Курсы валют.
- Проведение документов с контролем остатков и откатом движений.

### 🧮 Учётные механизмы
- **НДС:** ставки 22%, 10%, 0%, без НДС; расчёт, выделение из суммы, итоги по документу.
- **Складской учёт:** остатки по складам, перемещение между складами, контроль нехватки.
- **Ценообразование:** подстановка цен по организации и дате.
- **Взаиморасчёты:** контроль долгов контрагентов.

### 📊 Отчёты
- Список контрагентов, Список номенклатуры.
- Вхождение номенклатуры в документы.
- Остатки товаров, Продажи товаров.
- Отчёты на СКД.

### 🎨 Интерфейс
- Управляемые формы документов и справочников.
- Подсистемы: Закупки, Продажи, НСИ, Отчёты, Склады.

---

## 🏗 Архитектурные решения

- **Общие модули для переиспользования:** `РаботаСНДС`, `РаботаСЦеной`, `РаботаСТабличнымиЧастями`, `ИтогИСумма`.
- Пересчёт итоговой суммы документа с НДС, отдельный вывод суммы НДС, сумма документа прописью.
- Проверка номенклатуры по остаткам при её перемещении или расходе.
- Проверка, является ли контрагент поставщиком или покупателем, во время реализации или закупки через соответствующие документы.
- Отображение договоров, связанных с контрагентом (исключение чужих договоров).
- Создание документов на основании.
- Организация торгово-закупочного и общего журналов.
- Автоматическое подтягивание цен в документы на основе организации и регистрации цен.
- Вывод сообщений в интерфейс при ошибках.
